# 오라홀릭 게스트하우스 관리

세부 **오라홀릭 게스트하우스**의 A·B·C·D 4채를 사장님과 엘레나가 함께 운영하기 위한 웹앱(PWA)입니다.
휴대폰 홈 화면에 설치해 앱처럼 쓰고, 인터넷이 없어도 저장되며, 예약 확정서는 **오프라인에서 PNG로** 만들 수 있습니다.

## 하우스

| 하우스 | 구성 | 기본 인원 |
| --- | --- | --- |
| A하우스 | 5룸 · 독채 | 10명 |
| B하우스 | 3룸 · 뒷마당 | 6명 |
| C하우스 | 3룸 · 화장실 3개 | 6명 |
| D하우스 | 3룸 · 2층 테라스 | 6명 |

## 화면

### 📅 캘린더
- 월 단위로 A·B·C·D 4채의 입실·퇴실·숙박을 한눈에 봅니다.
- **하우스 색**: A하우스 앰버 · B하우스 에메랄드 · C하우스 스카이 · D하우스 바이올렛. 색은 하우스, 무늬는 상태를 뜻합니다.
  **입실**은 하우스 진한 색, **숙박**은 하우스 연한 색(왼쪽 굵은 띠), **퇴실**은 하우스 색 빗금입니다. 에어비앤비 예약은 앞에 동그라미가 붙습니다.
- **당일 턴오버**: 같은 날 퇴실과 입실이 있으면 한 칸이 **퇴실 | 입실**로 반씩 나뉘어 표시됩니다. (🌙 밤/새벽 비행기 표시)
- **3룸 빈방 한눈에**: 달력 위 요약 줄과 각 날짜 칸에 `3룸 2채 빈방` / `3룸 마감`이 색으로 표시됩니다.
- **3룸만 보기 B·C·D** / **5룸 A하우스** 필터.
- 날짜를 누르면 하우스별 입실·퇴실 상세와 턴오버 안내가 열립니다.

### ☀️ 오늘 운영
- 오늘 입실·퇴실, 숙박 중, 3룸 빈방, 보증금 할 일 수.
- **보증금 알림**: 입실 D-7 이내인데 아직 못 받은 보증금(수령 완료 버튼), 퇴실 후 아직 안 돌려준 보증금(반환 완료 버튼).
- 오늘 준비: 아떼 · 베이비시터 · 튜터 · 추가 매트리스.
- 내일 미리보기.

### 📋 예약
- 예약 추가·수정·삭제, 기간/하우스/구분 필터, 이름·연락처 검색.
- 입력 항목: 하우스, 예약 구분(개별/에어비앤비/기타), **대표 예약자명**, 연락처(선택), **입금자**, **투숙객 전원 성명**,
  입·퇴실 일시, 밤/새벽 비행기, 기본·추가 인원,
  **아떼(배정된 아떼 이름 포함) · 베이비시터 · 튜터 · 추가 매트리스**, 공항 픽업/샌딩,
  금액(총액·예약금·잔금), **보증금(금액·수령일·반환일)**, 항공편(항공사·편명·도착·출발), 특이사항.
- 예약 카드에 아떼·베이비시터·튜터·매트리스·추가인원·밤비행기·픽업/샌딩·보증금 배지와 **등록/수정한 사람**이 표시됩니다.

### 💬 손님 안내
- 원하는 입실·퇴실 날짜와 룸 타입을 고르면 가능한 하우스를 보여주고,
  턴오버(당일 퇴실 후 입실) 안내까지 넣은 **카카오톡용 한국어 문구**를 만들어 복사합니다.

### 🖼 확정서
- 예약을 고르면 예약자·숙박기간·금액·항공편이 자동으로 채워진 **오라홀릭 예약 확정서**를 만듭니다.
- 디자인·요금표·양도/취소 규정·입퇴실 안내는 원본 확정서 그대로 고정되어 있고,
  예약자/입금자/숙박인/동반자, 숙박기간, 시즌, 객실, 예약상태, 총 금액, 항공사·편명·도착·출발,
  금액 내역(숙박·아떼·픽업드랍·매트리스/기타), 추가 서비스 표기를 고칠 수 있습니다.
- **PNG로 저장**: `예약자명YYYY.MM.DD.png` (예: `김동준2027.07.02.png`). 모든 그림은 브라우저 Canvas로만 그려서
  **인터넷·외부 CDN 없이** 안드로이드 크롬에서도 저장됩니다.

### ⚙️ 설정
- **작업자**: `사장님` / `엘레나` / 직접 입력. 예약마다 `등록: 엘레나 · 수정: 사장님`처럼 기록됩니다.
- **🔒 접속 비밀번호**: 지금 비밀번호 + 새 비밀번호(4자 이상)로 바꿉니다. **지금 잠금** 버튼도 이곳에 있습니다.
- **공동 운영 동기화(Firebase Realtime Database)**: 3단계 안내대로 주소와 공유 코드를 넣으면
  상단 배지가 `공동 운영 동기화 연결됨`으로 바뀌고, 두 기기가 같은 장부를 실시간으로 주고받습니다.
  연결이 끊겨도 기록은 이 기기에 그대로 남습니다.
- JSON 내보내기/가져오기, **샘플 데이터 넣기**, 전체 초기화.

## 🔒 접속 비밀번호 잠금 (관리자 로그인)

앱을 열면 예약 장부 대신 **`오라홀릭 게스트하우스 · 관리자 로그인`** 카드가 먼저 나옵니다.
비밀번호를 맞히기 전에는 앱 화면(`#app-shell`)이 숨겨지고 예약 데이터도 그리지 않습니다.

| 항목 | 내용 |
| --- | --- |
| 처음 비밀번호 | **`0000`** (첫 화면에 안내가 뜨고, 설정에 `기본 0000` 배지가 붙습니다) |
| 이 기기에서 로그인 유지 | 체크(기본)하면 `localStorage`에 로그인을 남겨 다음부터 묻지 않고, 끄면 `sessionStorage`라 탭을 닫으면 다시 묻습니다 |
| 잠그기 | 상단 **🔒** 버튼 또는 **설정 → 지금 잠금** |
| 비밀번호 바꾸기 | **설정 → 🔒 접속 비밀번호** (지금 비밀번호 → 새 비밀번호 4자 이상 → 확인) |
| 사장님·엘레나 공유 | 공동 운영 동기화가 켜져 있으면 바꾼 비밀번호(해시)와 바꾼 시각이 Firebase에 함께 저장되어 상대 기기에도 전해집니다 |

- 비밀번호는 `localStorage`의 앱 상태(`security.pinHash`)에 **해시로** 저장되고, 바꾸면 그 기기의 로그인 기록도 새 비밀번호로 갱신됩니다.
- 전체 초기화를 해도 접속 비밀번호는 그대로 유지됩니다(예약만 지워집니다).

> ⚠️ **화면 잠금용입니다.** 앱을 여는 사람을 막아 주지만, 기기에서 브라우저 저장소를 직접 열어 보는 사람까지 막지는 못합니다.
> 특히 Firebase를 **테스트 모드**로 쓰면 누구나 그 주소를 읽고 쓸 수 있으므로, 손님 정보를 지키려면 Firebase 규칙을 잠그고 두 기기만 쓰세요.

## 공동 운영 동기화 설정 (사장님·엘레나 각각 한 번)

1. [Firebase 콘솔](https://console.firebase.google.com)에서 프로젝트를 만듭니다.
2. **빌드 → Realtime Database → 데이터베이스 만들기 → 테스트 모드**로 시작하고, 화면 위 주소
   (`https://....firebaseio.com`)를 복사합니다.
3. 앱 **설정 → 공동 운영 동기화**에 주소와 **같은 공유 코드**(예: `oraholic-cebu`)를 넣고 **연결 확인 및 켜기**를 누릅니다.

> ⚠️ 테스트 모드는 누구나 읽을 수 있습니다. 손님 개인정보가 걱정되면 Firebase 규칙을 잠그고 두 기기만 쓰는 것을 권합니다.

## 실행 · 배포

- `index.html`을 열면 바로 동작합니다. 모든 경로가 `./` 상대 경로라 GitHub Pages 하위 경로(`https://oraholic.github.io/...`)에서도 그대로 동작합니다.
- 아직 GitHub 저장소 생성·배포는 하지 않았습니다. (사용자 확인 후 진행)
- 오프라인 캐시: `sw.js`가 상대 경로 자산을 캐시합니다.

## 데이터

- 이 기기: `localStorage` 키 `oraholic-guesthouse-v1` (`bookings` + `settings` + `security` + `sync`).
- 로그인 유지: `localStorage` 키 `oraholic-guesthouse-auth-v1` (해제하면 `sessionStorage`).
- 백업: 설정 → JSON 내보내기. 예약 배열을 그대로 담습니다(비밀번호는 백업에 넣지 않습니다).
- 동기화: 예약 단위로 `updatedAt`이 최신인 쪽을 채택하고, 삭제는 tombstone으로 전파합니다.
