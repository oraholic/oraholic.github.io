# 오라홀릭 회계 정산 (Oraholic Accounting)

세부 오라홀릭 게스트하우스의 **필리핀 현지 지출**과 **한국 지출**, 그리고 **숙박 수입**을
월별로 정산하는 한국어 PWA입니다. 예약 앱(https://oraholic.github.io/)과는 **비밀번호·저장소가
완전히 분리된** 별도 앱입니다.

- 앱 주소: **https://oraholic.github.io/accounting/**
- 기본 접속 비밀번호: **`0000`** (설정 → 접속 비밀번호에서 꼭 바꿔 주세요)

## 화면

| 탭 | 하는 일 |
|---|---|
| 📊 정산 | **현재 보유 잔액**(필리핀 ₱ · 한국 ₩ · 통합 환산), 월 선택, 총 수입·총 지출·월 순수익, 항목별 지출 비중, 현지 vs 한국 비교, 전월 대비, 최근 내역, 지난달 고정비 1탭 복사 |
| 📒 장부 | 월·지역(현지/한국)·하우스(공통·A~D)·항목·검색으로 거른 내역 목록, 눌러서 수정/삭제 |
| 📈 분석 | 연간 12개월 추이, 월별 정산표, 하우스별 정산, 전체 기간 지출 순위 |
| ⚙️ 설정 | 기초 잔액, 환율(₱1 = ₩?), 접속 비밀번호, JSON/CSV 백업, 샘플 데이터, 초기화, Firebase 동기화 |

## 회계 규칙

- 모든 내역은 **지역**(🇵🇭 필리핀 현지 / 🇰🇷 한국)과 **통화**(₱ / ₩)를 함께 저장합니다.
  지역을 고르면 통화가 자동으로 맞춰지고, 필요하면 통화만 따로 바꿀 수 있습니다.
- **현재 보유 잔액**
  - 🇵🇭 `기초 ₱ + 누적 ₱ 수입 − 누적 ₱ 지출`
  - 🇰🇷 `기초 ₩ + 누적 ₩ 수입 − 누적 ₩ 지출`
  - 통합 환산 = `₩ 잔액 + ₱ 잔액 × 환율`
- **월 순수익** = 총 수입 환산 − 총 지출 환산 (환산은 `₱ 금액 × 환율`).
- 지출 항목 10종: 월세 · 인터넷 요금 · 마을 회비 · 에어비앤비 등록비/수수료 · 수도세 ·
  전기세 · 아떼 월급 · 수리 비용 · 물품 구입 · 기타 지출 (+ 직접 추가한 항목).
- 수입 항목: 숙박 수입 - 개별 · 숙박 수입 - 에어비앤비 · 추가 서비스(아떼/픽드랍/매트리스) · 기타 수입.
- **고정 지출**: 체크해 두면 다음 달에 「지난달 고정비 불러오기」로 한 번에 복사됩니다
  (이미 복사된 항목은 중복되지 않습니다).

## 저장과 백업

- 이 기기의 `localStorage` 키 `oraholic-accounting-v1`에 저장합니다.
  로그인 기록은 `oraholic-accounting-auth-v1`(로그인 유지 시 localStorage, 아니면 sessionStorage).
- **잠겨 있는 동안에는 어떤 금액도 화면에 그려지지 않습니다.**
- JSON 내보내기에는 장부와 설정만 담기고 **비밀번호 해시는 담기지 않습니다.**
- CSV(엑셀)는 보고 있는 달의 정산표를 BOM 포함 UTF-8로 내려받습니다.
- 동기화(선택): Firebase Realtime Database 주소 + 공유 코드를 넣으면
  `oraholic-accounting/{공유코드}.json` 경로로 사장님·엘레나 기기가 같은 장부를 봅니다.

## 개발

```
accounting/
├── index.html      잠금 화면 + 앱 껍데기(데이터는 잠금 해제 후에만 그립니다)
├── styles.css      세이지·포레스트 그린 팔레트
├── app.js          잠금·장부·집계·환율·백업·동기화 (window.__AC 로 테스트 노출)
├── manifest.json   PWA(상대 경로)
├── sw.js           회계 전용 캐시(예약 앱 캐시와 분리)
├── icon.svg · icon-192.png · icon-512.png · icon-maskable-512.png · favicon-32.png
└── tests/          jsdom 자동 테스트 78개
```

```bash
cd accounting/tests
npm install      # jsdom
npm test         # 78개 테스트
```

앱은 모두 상대 경로(`./`)라 `https://oraholic.github.io/accounting/`에서 그대로 설치됩니다.
